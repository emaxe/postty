## [0.1.0] - 2026-09-05

### Добавлено
- **Гибридная архитектура монорепозитория**: Настроены рабочие пространства pnpm, конвейеры сборки Turborepo и Cargo workspace для Rust.
- **Общий слой контрактов (`@postty/contracts`)**:
  - Строгие схемы Zod и TypeScript-модели для `RequestItem`, `Collection`, `Environment`, `Workspace`, `HttpResponse` и `SyncMutation`.
- **Базовый движок исполнения (`@postty/core`)**:
  - `VariableInterpolator`: Интерполятор шаблонов с поддержкой `{{env}}`, вложенных переменных и динамических генераторов Postman (`{{$guid}}`, `{{$timestamp}}`, `{{$randomInt}}`).
  - `RequestExecutor`: Модульный исполнитель запросов с автоматическим внедрением заголовков авторизации и расчетом метрик.
  - `FetchTransport`: Сетевой транспорт для Web и Node.js.
  - 100% покрытие юнит-тестами в Vitest.
- **Нативное ядро Rust (`crates/postty-core` и `crates/postty-sync`)**:
  - Асинхронный HTTP-клиент на `reqwest` и `rustls` для обхода ограничений CORS браузера, поддержки mTLS и кастомных SSL-сертификатов.
  - Локальное хранилище SQLite для офлайн-кэширования и дельта-мутаций.
- **Терминальный TUI и CLI (`apps/tui`)**:
  - Полноэкранный интерфейс Alternate Screen на базе `ratatui` и `crossterm`.
  - Полноценная поддержка мыши (клики по запросам, табам, кнопке отправки, скролл ответов колесиком).
  - Клавиатурная навигация с Vim-хоткеями (`j`/`k`), вкладками (`1`–`4`) и отправкой по `Enter`.
  - Консольный раннер коллекций (`postty run <collection>`).
  - Авторизация по коду устройства (`postty login`).
- **Веб-клиент (`apps/web`)**:
  - Современный SPA-интерфейс на React 18, Vite и Tailwind CSS.
  - Дерево коллекций и запросов с цветовой индикацией HTTP-методов.
  - Редактор запросов: таблицы параметров и заголовков, типы авторизации (Bearer, Basic, API Key), тела (JSON, urlencoded).
  - Инспектор ответа: бейджи статусов, время в миллисекундах, размер в килобайтах, форматированный JSON и копирование в буфер обмена.
  - Модальное окно управления переменными с маскировкой секретов.
  - Локальное сохранение состояния в `LocalStorage`.
- **Облачный бэкенд API (`apps/api`)**:
  - Сервер на Fastify с плагинами `@fastify/jwt` и `@fastify/cors`.
  - Маршруты аутентификации: регистрация, вход и профиль `/me`.
  - Полная реализация протокола OAuth 2.0 Device Authorization Grant (RFC 8628) для входа из консоли.
  - Управление личными и командными воркспейсами.
  - API двусторонней дельта-синхронизации (снимок состояния, отправка мутаций push, получение дельты pull).
- **Десктопное приложение (`apps/desktop`)**:
  - Оболочка на Tauri v2 с вызовом нативной Rust-команды `execute_native_http`.
  - Сетевые вызовы без ограничений CORS с поддержкой сертификатов и низким потреблением RAM (~40 МБ).
- **Мобильное приложение (`apps/mobile`)**:
  - Тач-клиент для iOS и Android на React Native и Expo.
  - Свайп запросов, переключение сред (Dev / Prod) и просмотр ответов с мобильного экрана.
- **Инструменты разработчика**:
  - Интерактивный терминальный скрипт `run.sh` с выводом исключительно через `printf`.
  - Архитектурные спецификации в `docs/init/` и инструкции для ИИ-агентов в `AGENTS.md`.
